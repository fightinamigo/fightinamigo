# Omar Rashad | Portfolio

Personal portfolio website: about me, projects, an interactive play corner (xG shot lab, sorting race, smart bins), skills, journey, certificates and contact.

Built with plain HTML, CSS and JavaScript. No build step needed.

## Structure

```
index.html
css/style.css
js/main.js
assets/photo.webp
assets/Omar_Rashad_Resume.pdf
```

## Run locally

Open `index.html` in a browser.

## Deploy

Import this repo on Vercel (Framework Preset: Other). Leave the build command and output directory empty.

## Edit content

- Projects, skills and the typing roles are in `js/main.js`.
- Colors and layout are in `css/style.css`.
- Text sections are in `index.html`.
